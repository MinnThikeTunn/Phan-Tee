# Windows Microcopy Guidelines

- **Sentence case:** Write button labels and section headers in sentence case ("Mark as completed", not "Mark As Completed").
- **Clear verbs:** Avoid generic "OK" for dialog actions; use the active verb ("Delete", "Discard", "Save").
- **Empty states:** State what is missing and provide the next step ("No items yet. Press Ctrl+N to add your first task.").
